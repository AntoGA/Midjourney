# Midjourney Editorial Photography Skills

Коллекция из 10 профессиональных навыков для создания изображений редакционного качества уровня топовых мировых фотографов.

## Описание

Этот репозиторий содержит тщательно подобранные промпты и параметры для Midjourney, которые позволяют создавать фотографии высокого редакционного качества, вдохновленные работами легендарных фотографов и современных мастеров индустрии.

## Структура

- `editorial_skills.md` — 10 детальных навыков с промптами
- `README.md` — описание проекта

## Использование

Каждый навык включает:
- **Название** — краткое описание стиля
- **Описание** — характеристика подхода и техники
- **Базовый промпт** — готовый шаблон для Midjourney
- **Параметры** — рекомендуемые настройки
- **Пример применения** — как адаптировать под конкретную задачу

## Требования

- Midjourney v6 или выше
- Подписка для доступа к профессиональным параметрам

## Автор

Создано для профессионального использования в редакционной и коммерческой фотографии.
