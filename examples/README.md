## Как использовать

1. Скопируйте промпт для нужного стиля
2. Вставьте в Midjourney
3. Сгенерируйте изображение
4. Сохраните в соответствующую папку с именем `example-01.jpg`, `example-02.jpg` и т.д.

## Примечания

- Все изображения должны быть сгенерированы с параметром `--v 6`
- Используйте `--style raw` для максимальной реалистичности
- Для fashion-снимков добавляйте `--q 2` для лучшего качества
- Сохраняйте оригинальные промпты в метаданных изображений
